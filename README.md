This website was developed for YAPPA Foundation as an informational and interactive platform to introduce the organization, 
its programs, activities, donation services, and volunteer opportunities. 
The website aims to provide users with easy access to information regarding YAPPA’s mission, social initiatives,
and community support programs for orphaned and underprivileged children.

In addition, the website includes several interactive features such as donation forms, 
volunteer registration forms, program activity sections, and responsive layouts to improve user experience. 
The overall design was created to appear modern, organized, and user-friendly while maintaining clear navigation and
accessibility for visitors.
